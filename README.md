# 국립목포대학교 조경학과 일정실
Mokpo National University, Dept of Landscape Architecture

교수·조교가 함께 사용하는 학과 행사 일정 웹 앱입니다. 타임라인, 전체 기간표, 월별 달력, 내규집 팝업, 구성원 로그인, 문서 첨부와 모바일 화면을 제공합니다.

## 실행
Node.js 22.13 이상을 사용합니다.

```sh
npm ci
mkdir .openai
# 로컬 개발: hosting.example.json을 .openai/hosting.json으로 복사
# 실제 배포: 새 Sites 프로젝트의 hosting.json 사용
npm run dev
npm run build
```

PDF 미리보기 자산은 설치된 pdfjs-dist에서 실행·빌드 전에 자동 복사합니다.

## 배포 설정
이 코드는 Cloudflare Workers D1(DB), R2(BUCKET), 신뢰할 수 있는 Sites 인증 게이트웨이를 전제로 합니다. 운영자가 서버 환경변수 OWNER_EMAIL을 설정해야 소유자 관리 로그인을 사용할 수 있습니다. 이 값은 클라이언트에 전달하지 마세요. 설정하지 않으면 소유자 권한을 부여하지 않습니다.

공개 저장소에는 운영 사이트 ID, 배포 자격증명, 환경변수 파일, 실제 일정·내규·구성원·첨부파일을 포함하지 않습니다. 새 Sites 프로젝트에서 제공받은 hosting 설정으로 배포하세요.

## 데이터베이스
`drizzle/0000_public_baseline.sql`은 빈 데이터베이스에 적용하는 공개용 초기 스키마입니다. 공통 초기 비밀번호나 기본 계정은 없습니다. 구성원은 관리자가 개별 비밀번호로 등록합니다.

**현재 운영 사이트의 과거 마이그레이션을 대체하지 마세요.** 기존 운영 DB를 업데이트할 때는 원래 마이그레이션 이력을 유지하고 애플리케이션 변경만 반영해야 합니다. 이 저장소는 개인정보를 제거한 새 설치용 소스 스냅샷입니다.

## 공개 범위
일정·내규·행사 첨부파일의 열람은 공개이며, 쓰기는 등록된 구성원, 구성원 관리는 관리자만 가능합니다. 비공개 문서용 서비스로 사용하려면 읽기 API에도 별도의 접근 제어를 구현해야 합니다. Sites 외부에 배포할 때는 인증 헤더를 직접 신뢰하지 말고 검증된 인증 공급자를 연결하세요.

보안 점검 범위와 제한은 SECURITY.md를 참고하세요.
